# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities as public GitHub Issues.**

Use [GitHub Private Security Advisories](../../security/advisories/new) to report a vulnerability privately. This allows us to assess and fix the issue before it is publicly disclosed.

Include in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Sweet Home 3D and plugin version

We aim to respond within 7 days and will credit you in the release notes if you wish.
